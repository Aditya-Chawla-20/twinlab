# TwinLab visual system

Original scientific workbench: warm off-white ground, ink text, cobalt measurements and amber predictions. A restrained instrument UI, not a marketing page. Spacious outside margin, compact within tools. Video on the left, reviewable analysis on the right, synchronized plot below. Navigation opens Experiment, Evidence and API usage views.

- Fonts: locally bundled sans; monospace reserved for measurements and timestamps.
- Components: 1px borders, 6–12px corner radii, visible selected/disabled/error/focus states. Authored SVG icons.
- Data: blue observations; dashed amber predictions; shaded validation region. Never rely on color alone.
- Mobile: stack work areas, retain native video controls, horizontally scroll only data tables.
- Interaction: user explicitly enters calibration or point-marking mode. Paid controls open a cost review dialog. No billing action on mount.
- Design service: 12ui draft attempted 2026-10-30 but requires sign-in; no design output exists. Hand-authored original design used to preserve progress and product behavior.
