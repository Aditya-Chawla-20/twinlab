TwinLab static browser demo

Serve this directory over HTTP, for example:
  python3 -m http.server 8080 --bind 127.0.0.1
Then open http://127.0.0.1:8080/ . Do not open index.html as file://.

Predict > Try recorded real footage loads the MIT-licensed filmed A/B example.
Review the 4-second prefix and same-setup assumption, then Evaluate prediction.
These are recorded Muse/SAM results, not new inference. This build has no API
key, no paid backend and makes no /api requests. Local manual analysis works.

Open demo/ for the narrated, captioned walkthrough. Read examples/README.md
for source hashes/derivation and notices/ for all bundled license notices.
Original app source, setup and limits: https://github.com/Aditya-Chawla-20/twinlab

Save project JSON for portable backups; one browser-local draft is not history.
Personal videos require relinking their original bytes after refresh. Pixel
prediction errors against SAM observations are not physical accuracy claims.
