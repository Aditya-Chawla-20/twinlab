## One line

Turn motion recordings into reviewable models, then test frozen dynamics on a separate release.

## Description

TwinLab is an experimental-video workbench for makers and prototype engineers. Muse Spark reviews video and proposes an analysis plan. SAM supplies frame-indexed object boxes/masks. The user reviews the landmark, axis, scale and assumptions; local TypeScript fits four explicit motion families on earlier observations and reports later validation.

The distinctive step is a separate-recording test: freeze A’s dynamics and source identity, align only B’s initial state using a declared prefix, then compare later B observations with the frozen prediction and simple baselines. Portable JSON/CSV/Markdown evidence retains partitions, provenance and input identities. The browser demo replays actual saved Meta results and supports local manual analysis without an API key.

## Actual Meta use and result

Muse Spark 1.3 proposes object/axis/family/assumptions; its prose is never a numerical parameter. SAM 3.1 provides segmentation/tracking. Explicit box-center or foreground-centroid observations feed deterministic calculations. No inference occurs during fitting or prediction.

On two MIT-licensed Morpheus filmed spring excerpts, a damped model from A’s420 earlier points predicts B after a predeclared4s/121-point alignment prefix. Later479-point RMSE2.98810px, persistence18.64277px and constant velocity22.71276px. These are errors against SAM trajectories. Approximate agent body-center reference agreement is weaker (A10.373/B8.386px); known scale and unchanged hidden capture conditions are not independently verified.

Ten authorized Meta requests across all generated/filmed tests total $0.5851035 from reported usage, including one deliberate repeat A tracking call to assess centroids. $8.40 conservative reservations remain intact under the $10 cap. Billing is provider-authoritative. Public demo visitors cannot spend owner credits.

## Original contribution

Original React/TypeScript workbench, observation/calibration workflow, deterministic model comparison/partitions, immutable frozen-model/source verification, initial-state-only transfer with baselines, evidence/recovery contracts, bounded Meta transport/testing and static key-free judge build. Open-source applications informed research; no application implementation was copied. Standard SDK/parser/framework/font dependencies and licensed footage are credited.

## Target audience and boundaries

Proposed audience: makers, prototype engineers and experimenters evaluating simple planar motion/settling. A camera-mount use case is a hypothesis; the supplied camera clip is AI-generated, while the public evidence uses filmed laboratory spring footage. No customer/demand, calibrated accuracy, superiority to Tracker, arbitrary physics discovery, validated intervention or structural-safety claim.
